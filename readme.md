# Práctica 1: Manejo Git

Repositorio para la práctica de manejo de repositorios Git.

## Descripción

Este proyecto contiene una pequeña página web con archivos HTML, CSS y JavaScript.  
Durante la práctica se trabajaron ramas, commits, merges, resolución de conflictos, uso de `.gitignore` y reversión de commits.

## Archivos principales

- `index.html`
- `page_a.html`
- `page_b.html`
- `styles/style.css`
- `scripts/script.js`
- `.gitignore`

## Ramas usadas

- `main`
- `feature_1`
- `feature_2`
- `fix_1`
